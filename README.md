# Crèches du monde – Église Saint-Étienne d'Ohain

Site de l'exposition des crèches de Noël, publié sur https://creches-ohain.be (GitHub Pages).

- `index.html`, `style.css`, `app.js` : gabarit du site (une seule page, navigation par `#`).
- `creches.json` : contenu des fiches. `sections.json` : sections (photo d'ensemble + ronds en % x/y).
- `site.json` : informations générales (dates, contact, responsable, compte pour les dons).
- `c-XXX.jpg`, `s-*.jpg` : photos web. Les originaux sont dans le Google Drive de l'exposition.
- `404.html` : adresses courtes pour les QR codes (`/c/C-012`, `/s/nom-de-section`, `/don`…).

Site géré bénévolement. Contact : contact@creches-ohain.be
